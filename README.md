# 관상동맥조영술 영상 분석: 혈관 분할부터 임상정보 Fusion까지

관상동맥조영술(X-ray Coronary Angiography, XCA) 영상을 이용해 혈관 분할, 협착 분류, 영상과 임상정보를 결합한 환자 단위 예측 모델을 비교한 개인 실험 프로젝트입니다.

처음에는 영상에서 혈관 영역을 분할하는 작업부터 시작했습니다. 이후 혈관을 잘 분할하는 것과 실제 협착을 정확하게 분류하는 것은 서로 다른 문제라는 점에 주목해 실험 범위를 확장했습니다.

데이터 전처리와 환자 단위 분할을 진행하고, U-Net과 MedicalSAM 계열 모델을 이용한 혈관 분할, ResNet 기반 협착 분류, Clinical AI와 XCA 모델의 Late Fusion까지 비교했습니다.

특히 성능 지표가 개선되더라도 특정 혈관 영역을 놓치거나 질환을 가진 환자에 대한 민감도가 감소하는 경우가 있어, 수치뿐 아니라 모델의 한계도 함께 분석했습니다.

위 그림은 DCA1 혈관 분할 실험과 AngioCAD 환자 단위 Fusion 실험의 주요 결과입니다. 두 실험은 사용하는 데이터와 평가 대상이 서로 다릅니다.

## 1. 프로젝트 배경

관상동맥조영술은 조영제를 이용해 관상동맥의 형태와 협착 상태를 확인하는 검사입니다.

하지만 영상에서 혈관을 구분하는 작업과 특정 혈관 분절의 협착 정도를 분류하는 작업은 목적과 정답 데이터가 다릅니다.

혈관 분할 모델이 높은 Dice Score를 기록하더라도 그 결과만으로 협착의 위치나 중증도를 정확하게 판단할 수는 없습니다.

이번 실험에서는 이러한 차이를 확인하기 위해 다음과 같이 접근했습니다.

1. AngioCAD 데이터의 구조와 라벨을 확인하고 전처리
2. DCA1 데이터로 혈관 분할 모델 학습 및 평가
3. 학습한 분할 모델의 AngioCAD 영상 적용
4. ResNet 기반 협착 분류와 Grad-CAM 분석
5. 임상정보와 XCA 영상을 결합한 환자 단위 Fusion 비교

각 단계의 성능을 하나의 지표로 합치지 않고, 평가 대상과 조건에 따라 구분했습니다.

## 2. AngioCAD 데이터 분석과 전처리

### 2.1 데이터 구조 및 품질 확인

모델 학습에 앞서 AngioCAD 데이터의 환자, Series, Frame, 협착 라벨 구조를 확인했습니다.

초기 데이터 확인 과정에서 영상 폴더 413개와 전체 121,566프레임을 점검했습니다.

주요 확인 항목은 다음과 같습니다.

- 영상 크기 및 프레임 수의 불일치
- 비정상적으로 짧거나 긴 Series
- 협착 라벨 범위와 순서
- 임상정보 누락 여부
- 환자 간 중복 영상 가능성

환자 간 영상 중복 여부는 Pixel Hash를 이용해 확인했고, 학습 대상 선정과 제외 기준을 정리했습니다.

### 2.2 환자 단위 데이터 분할

관상동맥조영술은 한 환자에게 여러 Series와 Frame이 존재할 수 있습니다.

따라서 Frame 단위로 학습·평가 데이터를 무작위 분할하면 동일 환자의 영상이 양쪽에 포함되는 데이터 누수가 발생할 수 있습니다.

이를 방지하기 위해 환자 단위로 데이터를 분리한 뒤, 해당 환자의 Series와 Frame에도 동일한 분할 정보를 적용했습니다.

| 구분 | 환자 수 |
|---|---:|
| 영상 보유 환자 | 412명 |
| Development | 329명 |
| Test | 83명 |
| 임상정보와 영상을 모두 보유한 Development 환자 | 303명 |

Development 데이터에는 이후 모델 비교를 위한 5-fold 정보를 부여했습니다.

### 2.3 영상 전처리

XCA 영상의 대비와 혈관 특징을 비교하기 위해 CLAHE 기반 전처리 조합을 구성했습니다.

원본 영상을 3채널로 복제한 방식, 원본과 서로 다른 CLAHE 결과를 조합한 방식, CLAHE 결과를 3채널로 복제한 방식 등을 비교할 수 있도록 준비했습니다.

이 과정에서는 단순히 영상의 대비를 높이는 것뿐 아니라 동일 환자와 영상에 대한 데이터 연결 관계가 유지되는지도 중요하게 확인했습니다.

자세한 데이터 처리 과정은 [실험 과정](docs/experiments.md)에 정리했습니다.

## 3. DCA1 데이터 기반 혈관 분할 실험

### 3.1 U-Net 모델 학습

혈관 분할 모델을 정량 평가하기 위해 픽셀 단위 정답 마스크가 제공되는 DCA1 데이터셋을 사용했습니다.

총 134장의 영상으로 U-Net을 학습했으며, 초기에는 작은 표본에 대한 Overfitting 실험으로 학습 코드가 정상 동작하는지 확인했습니다.

이후 이미지 단위 5-fold Out-of-Fold(OOF) 평가를 진행했습니다.

DCA1에는 환자 ID 정보가 없어 환자 단위 데이터 분할까지 보장하지는 못했습니다.

### 3.2 혈관 분할 성능 비교

| 모델 및 방법 | 평가 조건 | Pooled Dice |
|---|---|---:|
| **U-Net 128 Raw** | 128×128, Threshold 0.5 | **0.7259** |
| **U-Net 128 + 후처리** | 16px 미만 연결 요소 제거 | **0.7323** |
| U-Net 256 Raw | 256×256, Threshold 0.5 | 0.7090 |
| MedicalSAM3 Text Prompt | `coronary artery`, Confidence 0.1 | 0.2565 |

U-Net 128에서는 작은 연결 요소를 제거하는 후처리를 적용했을 때 Dice가 0.7259에서 0.7323으로 증가했습니다.

그러나 모든 영상에서 개선된 것은 아니었습니다.

일부 사례에서는 노이즈와 함께 실제 혈관 영역도 제거됐습니다.

또한 Hough Transform으로 카테터를 제거하는 방법을 시도했지만, 특정 영상에서 실제 혈관까지 제거돼 Dice가 크게 감소하는 문제가 있었습니다.

따라서 평균 성능만 보고 후처리를 선택하기보다는 실제 혈관 구조가 유지되는지도 함께 확인했습니다.

후처리 방식은 동일한 OOF 결과를 보고 선택했으므로, 이 수치를 독립 테스트 성능의 개선으로 해석하지 않았습니다.

### 3.3 입력 해상도 비교

U-Net 256 모델도 학습했지만, 이번 실행의 OOF Dice는 0.7090으로 U-Net 128보다 낮았습니다.

다만 두 모델은 각 입력 해상도에 맞게 변환한 정답 마스크로 평가했고, 학습 이력도 동일하지 않았습니다.

따라서 이 결과만으로 입력 해상도가 높을수록 성능이 낮아진다고 단정할 수는 없습니다.

## 4. AngioCAD 영상 적용과 MedicalSAM 실험

### 4.1 학습한 U-Net 모델 적용

DCA1에서 학습한 U-Net 128의 5개 모델을 AngioCAD 영상의 12개 Series, 36개 Frame에 적용했습니다.

이를 통해 다른 관상동맥조영술 데이터에서도 혈관 영역이 어떻게 분할되는지 확인했습니다.

다만 AngioCAD에는 해당 실험을 위한 픽셀 단위 혈관 정답 마스크가 없어 정성적으로만 살펴봤습니다.

따라서 DCA1에서 측정한 Dice를 AngioCAD의 분할 성능으로 소개하지 않았습니다.

### 4.2 MedicalSAM3 비교

사전학습된 MedicalSAM3를 활용해 Text Prompt 기반 혈관 분할을 실험했습니다.

`coronary artery`라는 고정 Prompt를 적용한 결과 DCA1의 128×128 평가 기준에서 Pooled Dice 0.2565를 기록했습니다.

추가로 정답 마스크에서 생성한 Bounding Box를 제공했을 때는 Native 해상도 기반 Macro Mean Dice 0.7108을 확인했습니다.

그러나 이 방식은 정답에서 유도한 위치 정보를 입력으로 사용한 진단 실험입니다.

자동 Text Prompt만 사용하는 방법과 조건이 다르므로 동일한 자동 분할 성능으로 비교할 수는 없습니다.

[MedicalSAM3 Prompt 진단 결과](figures/sam3_prompt_diagnostics.png)

### 4.3 멀티모달 모델을 활용한 Prompt 생성

Text Prompt만으로 원하는 혈관을 구분하기 어려운 문제를 살펴보기 위해 GPT-4o와 Qwen2.5-VL을 활용한 Text 및 Bounding Box 생성 실험도 진행했습니다.

하지만 모델이 정상적인 JSON 형식의 응답을 반환하거나 마스크를 생성했다고 해서, 해당 마스크가 실제 혈관 구조와 일치하는 것은 아니었습니다.

서로 다른 혈관 이름을 입력했는데도 거의 동일한 마스크가 반환되는 사례가 있었고, 일부 사례는 수동 평가를 완료하지 못했습니다.

MedSAM2 코드에 CA-SAM2 가중치를 연결한 단일 사례에서는 생성된 세 후보 마스크가 모두 지정한 Positive Point를 포함하지 않는 문제도 확인했습니다.

이 과정에서 모델 출력의 형식적 성공 여부와 해부학적 정확성을 별도로 검증해야 한다는 점을 알게 됐습니다.

## 5. ResNet 기반 협착 분류 실험

### 5.1 협착 등급 분류

혈관 분할과 별도로, XCA 영상에서 협착 정도를 분류하기 위해 ResNet50 기반 모델을 실험했습니다.

15개 관상동맥 분절에 대한 7등급 분류와 View 단위의 50% 초과 협착 여부 예측을 진행했습니다.

초기 7등급 분류의 검증 결과는 다음과 같았습니다.

| 평가 지표 | 결과 |
|---|---:|
| QWK | 0.3527 |
| Balanced Accuracy | 0.2731 |

이후 라벨을 3개 구간으로 단순화하고 학습 설정도 변경했습니다.

| 평가 지표 | 변경 전 | 변경 후 |
|---|---:|---:|
| QWK | 0.3527 | 0.3898 |
| Balanced Accuracy | 0.2731 | 0.5026 |
| Over 50% AUROC | 0.8191 | 0.8068 |

라벨을 단순화한 실험에서는 QWK와 Balanced Accuracy가 개선됐지만, 50% 초과 협착 여부를 구분하는 AUROC는 오히려 감소했습니다.

또한 라벨 구성과 학습 설정이 함께 변경됐기 때문에 개선 원인을 라벨 단순화 하나로 단정할 수는 없습니다.

위 결과는 Validation 기준이며, 해당 실험의 최종 Test 결과는 확보하지 못했습니다.

### 5.2 근위부 혈관 분류와 Grad-CAM

별도의 환자 단위 70/15/15 분할 실험에서는 ResNet18로 근위부 LCX와 LAD의 정상(NL) 및 이상(Abnormal) 여부를 분류했습니다.

Test 환자 62명에 대해 환자별 평균 확률을 평가한 결과는 다음과 같았습니다.

| 분류 대상 | Test ROC-AUC |
|---|---:|
| Prox LCX | 0.7190 |
| Prox LAD | 0.6393 |

[근위부 혈관 분류 결과](figures/prox_classification.png)

추가로 Grad-CAM과 Threshold 기반 Pseudo-mask를 이용해 모델이 영상의 어느 부분에 반응하는지 살펴봤습니다.

다만 병변 위치에 대한 정답 데이터와 직접 비교한 결과는 없으므로, 이를 협착 위치의 정확한 탐지 또는 분할 성능으로 해석하지 않았습니다.

## 6. 임상정보와 XCA 영상의 Late Fusion

### 6.1 실험 목적과 모델 구성

마지막으로 영상 모델과 임상정보 모델을 결합했을 때 환자 단위 분류 성능이 어떻게 달라지는지 비교했습니다.

AngioCAD Development 환자 중 영상과 임상정보를 모두 사용할 수 있는 303명을 대상으로 5-fold OOF 평가를 진행했습니다.

사용한 모델은 다음과 같습니다.

- **Clinical-only:** 임상정보 기반 AdaBoost
- **XCA-only:** ResNet50 기반 Attention MIL
- **Late Fusion:** 두 모델의 예측 확률을 1:1로 평균

Target은 `any_definite_over_50`이며, 분류 Threshold는 0.5로 설정했습니다.

### 6.2 모델별 결과

| 모델 | ROC-AUC | Sensitivity | Specificity | Accuracy |
|---|---:|---:|---:|---:|
| Clinical-only | 0.8257 | **0.7637** | 0.7727 | **0.7657** |
| XCA-only MIL | 0.8197 | 0.4599 | **0.9091** | 0.5578 |
| **Late Fusion** | **0.8662** | 0.7089 | 0.8788 | 0.7459 |

![Clinical·XCA·Late Fusion 성능 비교](figures/fusion_tradeoff.png)

### 6.3 결과 분석

Late Fusion은 Clinical-only보다 ROC-AUC가 0.8257에서 0.8662로 증가했습니다.

Specificity도 0.7727에서 0.8788로 높아졌습니다.

반면 Sensitivity는 0.7637에서 0.7089로 감소했고, Accuracy도 0.7657에서 0.7459로 낮아졌습니다.

환자 단위 Paired Bootstrap 분석에서는 Fusion과 Clinical-only의 AUROC 차이가 +0.0405였으며, 95% 신뢰구간은 [+0.0169, +0.0657]이었습니다.

그러나 Sensitivity 차이는 -0.0549로 나타났습니다.

즉, 영상과 임상정보를 결합했을 때 전반적인 구분 능력은 개선됐지만, **CAD 선별 관점에서 중요한 민감도는 오히려 낮아졌습니다.**

이번 실험을 통해 서로 다른 데이터를 결합한다고 해서 모든 평가 지표가 동시에 좋아지는 것은 아니라는 점을 확인했습니다.

또한 Fusion 방식이 실제 선별에 적절한지는 AUROC뿐 아니라 False Negative와 Specificity 사이의 균형을 함께 고려해야 한다고 생각했습니다.

이 결과는 개발 데이터의 OOF 평가이며, 별도 Test 및 외부 검증 결과는 아닙니다.

## 7. 주요 문제와 검토 과정

### 7.1 데이터 누수 방지

한 환자에게 여러 영상이 존재하는 데이터의 특성상 Frame 단위 무작위 분할은 평가 결과를 왜곡할 수 있었습니다.

이를 방지하기 위해 AngioCAD에서는 환자 단위 데이터 분할을 먼저 수행하고 Series 및 Frame에 동일한 분할 정보를 적용했습니다.

### 7.2 혈관 분할 후처리의 한계

작은 연결 요소 제거는 평균 Dice를 개선했지만 일부 영상에서는 정상 혈관 영역도 함께 제거했습니다.

카테터를 제거하기 위해 적용한 Hough 기반 후처리에서도 실제 혈관을 손상시키는 사례가 있었습니다.

따라서 평균 성능 향상과 실제 혈관 구조 보존을 함께 검토할 필요가 있었습니다.

### 7.3 Prompt 기반 모델의 정확성 문제

MedicalSAM과 멀티모달 모델을 연결한 실험에서는 형식적으로 정상적인 결과가 나와도 해부학적으로 정확한 분할인지 판단하기 어려운 경우가 있었습니다.

특히 모델이 반환한 Confidence 또는 Mask 생성 여부만으로 분할의 정확성을 판단할 수 없었습니다.

향후에는 다수의 환자 영상과 전문가 평가를 통해 결과를 검증할 필요가 있습니다.

### 7.4 Fusion 성능의 상충 관계

Late Fusion의 AUROC와 Specificity는 증가했지만 Sensitivity는 감소했습니다.

CAD 선별을 목적으로 하는 경우에는 질환이 있는 환자를 놓치는 비율이 중요한 만큼, Fusion의 이득과 손실을 함께 평가해야 한다는 점을 확인했습니다.

## 8. 실험을 통해 배운 점

이번 프로젝트를 진행하면서 **모델의 성능을 평가할 때는 무엇을 예측하는 모델인지, 어떤 데이터로 평가했는지를 먼저 구분해야 한다**는 점을 배웠습니다.

혈관 분할의 Dice, 협착 분류의 AUROC, 환자 단위 Fusion의 Sensitivity는 서로 다른 목적을 가진 지표입니다.

따라서 특정 모델의 수치가 높다는 이유만으로 전체 관상동맥질환 분석 성능이 좋아졌다고 판단할 수는 없었습니다.

또한 영상 전처리와 후처리, 모델 구조, 임상정보 결합 등 다양한 접근을 시도하면서 **평균 지표의 개선이 개별 사례의 개선을 보장하지 않는다**는 점도 경험했습니다.

앞으로는 새로운 모델을 적용하는 것뿐 아니라, 데이터의 구조와 정답 정보, 평가 기준 및 실제 활용 목적을 함께 고려해 실험을 설계하고자 합니다.

### 향후 개선 방향

현재 결과는 각 데이터셋의 내부 실험과 일부 정성 평가를 중심으로 정리한 것입니다.

추후에는 다음 작업을 진행할 필요가 있습니다.

- AngioCAD 영상에 대한 픽셀 단위 분할 정답 확보 및 평가
- MedicalSAM·멀티모달 Prompt 결과의 다환자·전문가 평가
- Prompt 입력 및 저장 경로 불일치 사례 원인 분석
- MedSAM2의 Positive Point 미포함 문제 확인
- 협착 분류와 Fusion 모델의 고정된 Test 및 외부 데이터 검증
- 선별 목적에 맞는 Sensitivity·Specificity 균형 및 Threshold 검토

현재 성능을 독립 외부 검증이나 임상 적용 성능으로 해석하지 않습니다.
