# 공개 범위와 추가 확인

이 공개용 사본에는 본인 실험 코드와 집계 결과만 담았습니다. 원본 의료영상·GT·예측mask·overlay·crop·CAM이미지·환자별표·개별OOF·원본archive·가중치를 포함하지 않았습니다. 모든 노트북 저장출력과widget/첨부metadata를 비웠고, 코드에 있던 환자별 정정값·선택사례·수동좌표를 비공개 입력으로 분리했습니다.

의료영상이라는이유만으로영구삭제나공개금지를판정한것은아닙니다. AngioCAD와DCA1의정확한라이선스를확인하기전까지원본과파생의료이미지를이사본에서보류한것입니다. 집계그림은개별영상없이CSV에서재생성했습니다. 자세한조건은 [출처문서](data_sources.md)에있습니다.

## 남은 확인

- AngioCAD 개별Zenodo레코드의라이선스·배포버전,사용원본과의checksum대조
- DCA1 원배포README/라이선스·공식인용
- 사용모델의코드/가중치라이선스와복사한제3자코드의표시조건
- 공개할본인코드의소프트웨어라이선스선택. 데이터라이선스를그대로적용하지않음
- 실제학습재실행,입력provenance불일치와point미포함문제,사람평가·외부검증

실제API key는포함하지않았고GPT-4o외부전송은명시적활성화가필요합니다. 기존노트북을재실행하면환자별출력·영상·API전송이생길수있으므로새출력은다시검토해야합니다. 정적검사는모든형식의민감정보부재나법적공개허가를보증하지않습니다.

기존팀저장소의현재파일·Git기록은그대로입니다. 이폴더를별도로공개하더라도기존저장소에남은과거출력이회수되지는않습니다. 원본정리나기록재작성은팀과별도결정할작업입니다.
